The figure is the first sample minus the last, so the scatter always covers it, and one run cannot say whether the movement is the pipeline changing speed, the publisher's media clock running against wall clock, or which two segments happened to land at the ends. Read it as a reason to distrust a single run as a baseline rather than as a measurement of any of the three.

A run where that hop is finally non-negative and this gap is wide has not settled anything.
